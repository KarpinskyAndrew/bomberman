Static HTML layouts for every screen in docs/GUI-PLAN.md §3–4. They are design references, not the Vue app: no backend, fake data, and links that only move between mockups. Open a screen, then use the Mockups button in the bottom-right corner to switch screens and states (modals, overlays, guest view…). Each state also has its own URL hash, listed under the cards.
